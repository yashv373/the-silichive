SRAM Cell Design

category: memory status: active

Static Random-Access Memory (SRAM) is the workhorse of on-chip memory. Caches, register files, and buffers all rely on SRAM. Understanding the 6T cell is fundamental to any embedded memory design work.

The 6T SRAM Cell

The standard 6T SRAM cell consists of two cross-coupled inverters (4 transistors for storage) and two access transistors (for read/write operations via the bitlines). 

                  BL          BLB
                  │            │
            WL ──┤ M5         M6 ├── WL
                  │            │
                  ├────┐  ┌────┤
                  │    │  │    │
               ┌──┴──┐│  │┌──┴──┐
          VDD──┤ M3  ├┘  └┤ M4  ├──VDD
               └──┬──┘    └──┬──┘
                  Q          QB
               ┌──┴──┐    ┌──┴──┐
          GND──┤ M1  ├┐  ┌┤ M2  ├──GND
               └──┬──┘│  │└──┬──┘
                  │   └┘  └┘   │
                  └────────────┘

  M1, M2: Pull-down NMOS (drive)
  M3, M4: Pull-up PMOS (load)
  M5, M6: Access NMOS (pass gate)

Read Operation

During a read, both bitlines are precharged to VDD, then the wordline (WL) is asserted. The stored values create a differential voltage on BL and BLB. The sense amplifier detects this difference.

Read stability concern: The read operation is inherently destructive-prone. When the access transistor connects the storage node storing '0' to the precharged bitline, current flows into the cell, temporarily raising the voltage on that node. If this voltage exceeds the trip point of the opposing inverter, the cell flips — a read upset.

Stability Metrics

Metric Measures Design Lever
SNM (Static Noise Margin) Hold stability Inverter sizing, VDD
RSNM (Read SNM) Read stability Cell ratio (CR)
WM (Write Margin) Writeability Pull-up ratio (PR)

Cell Ratio (CR)

CR = (W/L)pulldown / (W/L)access

Higher CR improves read stability but increases cell area. Typical values: 1.2 to 2.0. This is the primary knob for RSNM optimization.

Pull-up Ratio (PR)

PR = (W/L)access / (W/L)pullup

Higher PR improves writeability. The access transistor must be able to overpower the pull-up PMOS during write. But too high a PR degrades read stability.

Design Tension

Read stability and writeability are fundamentally conflicting. Improving one degrades the other. This is the central challenge of 6T SRAM cell design and the reason alternative cell topologies (8T, 10T) exist.

Write Operation

During a write, one bitline is driven low while the other stays high. The access transistor on the low side must overpower the pull-up PMOS to flip the stored value. This requires careful sizing of the access-to-pullup ratio.

Advanced Considerations

  • Process variation: At advanced nodes, random dopant fluctuation (RDF) and line-edge roughness (LER) cause significant Vth variation, directly impacting stability margins
  • Assist techniques: Wordline underdrive (for read), negative bitline (for write), and body biasing are common techniques to improve margins
  • FinFET SRAM: Quantized fin widths constrain sizing ratios, requiring different optimization strategies compared to planar CMOS
  • Bitcell area: SRAM bitcell density is a key technology metric — often quoted in nm² per bit for node comparison
